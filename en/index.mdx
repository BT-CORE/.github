BT CORE is a modular resource ecosystem for [Open2077](https://open2077.net/).
The central `bt_core` resource owns character identity, persistent state and
the contracts used by banking, housing, factions, shops, vehicles and the other
resources documented on this site.

<Warning>
The current `bt_core 0.8.3` pages are a **preview generated from the development
candidate**. The corresponding runtime release has not been published yet.
</Warning>

## What the core provides

- civil identity and character onboarding;
- session lifecycle, placement, death and respawn;
- server-authoritative combat policy and sprint stamina drain;
- cash, bank accounts and extensible currencies;
- persistent inventory, experience, roles and permissions;
- multiple salaried jobs;
- persistent garages and owned vehicles;
- language, last position and playtime;
- a branded health, armor and stamina HUD.

## Documented version

This preview describes `bt_core` version `0.8.3` as declared by the development
manifest. The last local publication candidate remains `0.8.2`. The preview
targets Open2077 `>=0.0.1`.

## Start here

1. [Install the core](./core/installation).
2. [Review the server configuration](./core/configuration).
3. Choose the [client character exports](./core/reference/client),
   [client HUD exports](./core/reference/client-ui), or the clearly separated
   server reference.
4. Expand the return fields directly below each structured export, including
   snapshots, UI state, jobs and vehicles.
5. Check the [permissions and public limits](./core/events-permissions)
   before enabling the resource.
6. Browse the [resource catalog](./resources/catalog) to follow the rest of the
   ecosystem.

<Note>
Only resources with complete, versioned pages are considered installable. A
catalog entry marked preview or pre-release is not a published package.
</Note>
