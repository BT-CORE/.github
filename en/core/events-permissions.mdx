## Public limits

`bt_core` exposes no command and no network event for third-party resources.
Events prefixed with `bt_core:` drive the internal session, onboarding and HUD.
They are not a stable integration contract and must not be emitted externally.

Use exports for cross-resource integration. Server exports require a loaded
character except `listJobCatalog` and `listGarages`. Always handle `false` or
`nil` from a write.

## Security boundary

Persistent mutations run on the server. Do not expose these exports directly
to untrusted client payloads. Validate the caller's authorization and all
domain inputs in the resource that receives the network request.
