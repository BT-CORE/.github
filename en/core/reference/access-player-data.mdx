---
title: "Server exports — Access control"
description: "Read numeric access levels and manage free-form character roles."
icon: "user-shield"
---

Call these **server exports** with `Open77.exports.call(...):await()`. The
character must be loaded for every mutation.

## `getPermissionLevel`

Returns the stored numeric permission level.

```lua
local level = Open77.exports.call("bt_core", "getPermissionLevel", playerId):await()
```

<ResponseField name="permissionLevel" type="integer" required>
  Stored level, or `0` when the character is unavailable.
</ResponseField>
## `getRoles`

Returns the assigned free-form staff role keys. Treat the returned table as read-only.

```lua
local roles = Open77.exports.call("bt_core", "getRoles", playerId):await()
```

<ResponseField name="roles" type="string[]" required>
  Assigned keys, or an empty list when the character is unavailable.
</ResponseField>

## `hasRole`

Checks whether a free-form role key is assigned. There is no predefined role list.

<ParamField body="playerId" type="integer" required>Runtime player identifier.</ParamField>
<ParamField body="role" type="string" required>Exact free-form role key.</ParamField>

```lua
local moderator = Open77.exports.call("bt_core", "hasRole", playerId, "moderator"):await()
```

<ResponseField name="hasRole" type="boolean" required>`true` only when the key is assigned.</ResponseField>

## `giveRole`

Assigns a role that the character does not already hold.

```lua
local ok = Open77.exports.call("bt_core", "giveRole", playerId, "moderator"):await()
```

<ResponseField name="success" type="boolean" required>
  `false` when the character is unavailable, the role is invalid, or it is already assigned.
</ResponseField>

## `removeRole`

Removes an assigned role.

```lua
local ok = Open77.exports.call("bt_core", "removeRole", playerId, "moderator"):await()
```

<ResponseField name="success" type="boolean" required>
  `false` when the character is unavailable or the role is not assigned.
</ResponseField>
