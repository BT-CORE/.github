These exports exist only in a **client script**. Readiness, spawning and
onboarding remain authoritative: a `show` call cannot bypass those gates.

## `hideUI`

Applies the global hide override to the custom HUD and watermark.

```lua
local ok = Open77.exports.call("bt_core", "hideUI"):await()
```

<ResponseField name="success" type="boolean" required>Always `true`.</ResponseField>

## `showUI`

Releases the global hide override. Components become visible only when gameplay
UI is allowed and their component-level override is also released.

```lua
local ok = Open77.exports.call("bt_core", "showUI"):await()
```

<ResponseField name="success" type="boolean" required>Always `true`.</ResponseField>

## `hide`

Hides one UI component.

<ParamField body="component" type="string" required>
  `hud`, `watermark`, `all`, or `ui`. `all` and `ui` select the global override.
</ParamField>

```lua
local ok, errorCode = Open77.exports.call("bt_core", "hide", "hud"):await()
```

<ResponseField name="success" type="boolean" required>`false` for an unknown component.</ResponseField>
<ResponseField name="errorCode" type="string | nil">`unknown_ui_component` when rejected.</ResponseField>

## `show`

Releases one component-level hide override.

<ParamField body="component" type="string" required>
  `hud`, `watermark`, `all`, or `ui`. `all` and `ui` select the global override.
</ParamField>

```lua
local ok, errorCode = Open77.exports.call("bt_core", "show", "watermark"):await()
```

<ResponseField name="success" type="boolean" required>`false` for an unknown component.</ResponseField>
<ResponseField name="errorCode" type="string | nil">`unknown_ui_component` when rejected.</ResponseField>

## `isVisible`

Returns effective visibility after readiness, spawn, onboarding, global-hide and
component-hide checks.

<ParamField body="component" type="string" required>
  `hud`, `watermark`, `all`, or `ui`. For `all`/`ui`, `true` means at least one
  public component is visible.
</ParamField>

```lua
local visible, errorCode = Open77.exports.call("bt_core", "isVisible", "hud"):await()
```

<ResponseField name="visible" type="boolean | nil">Effective visibility, or `nil` for an unknown component.</ResponseField>
<ResponseField name="errorCode" type="string | nil">`unknown_ui_component` when rejected.</ResponseField>

## `uiState`

Returns all public UI gates and effective visibility flags.

```lua
local state = Open77.exports.call("bt_core", "uiState"):await()
if state.allowed and not state.hud then
    print("The HUD is hidden by an override")
end
```

<ResponseField name="state" type="UIState" required>
  Current gates and effective component visibility.
</ResponseField>

<Expandable title="Show UIState fields">
  <ResponseField name="allowed" type="boolean" required>Whether readiness, spawning and onboarding permit gameplay UI.</ResponseField>
  <ResponseField name="allHidden" type="boolean" required>Whether `hideUI()` applied the global override.</ResponseField>
  <ResponseField name="hud" type="boolean" required>Effective custom HUD visibility.</ResponseField>
  <ResponseField name="watermark" type="boolean" required>Effective watermark visibility.</ResponseField>
</Expandable>
