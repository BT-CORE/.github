These exports exist only in a **client script**. Call them through
`Open77.exports.call(...):await()` without a `playerId`.

## `isReady`

Returns whether the local client received the authoritative `bt_core:ready`
payload and currently owns a character snapshot.

```lua
local ready = Open77.exports.call("bt_core", "isReady"):await()
if not ready then return end
```

<ResponseField name="ready" type="boolean" required>
  `true` after `bt_core:ready`; reset to `false` when the Open2077 session ends.
</ResponseField>

## `snapshot`

Returns the character payload captured when `bt_core:ready` was received.

```lua
local player = Open77.exports.call("bt_core", "snapshot"):await()
if not player then return end

print(("Welcome %s %s"):format(player.firstname, player.lastname))
```

<ResponseField name="snapshot" type="CharacterSnapshot | nil">
  The last readiness snapshot, or `nil` before readiness and after session end.
  See the complete [CharacterSnapshot contract](./contracts#charactersnapshot).
</ResponseField>

<Warning>
The client snapshot is not updated after every server mutation. Treat it as
read-only bootstrap data. For a fresh value, call the relevant server export or
the server `snapshot(playerId)` export from a server script.
</Warning>
