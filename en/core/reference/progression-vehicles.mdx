---
title: "Progression"
description: "Read and mutate persistent character experience."
icon: "chart-line"
---

Call these **server exports** with `Open77.exports.call(...):await()`. The
character must be loaded.

## `getXp`

Returns the character's experience points.

```lua
--- getXp(playerId)
---@param playerId integer Runtime player identifier.
---@return integer xp Current XP, or 0 when the character is unavailable.

local xp = Open77.exports.call("bt_core", "getXp", playerId):await()
```

## `setXp`

Sets the experience total. `amount` is rounded down and clamped to `0`.

```lua
--- setXp(playerId, amount)
---@param playerId integer Runtime player identifier.
---@param amount number Value rounded down and clamped to 0.
---@return boolean success False when the character or value is invalid.

local ok = Open77.exports.call("bt_core", "setXp", playerId, 1000):await()
```

## `addXp`

Adds a non-zero positive or negative amount. The final total cannot be negative.

```lua
--- addXp(playerId, amount)
---@param playerId integer Runtime player identifier.
---@param amount number Non-zero delta.
---@return boolean success False when the character or delta is invalid.

local ok = Open77.exports.call("bt_core", "addXp", playerId, 25):await()
```
