Call these server exports with `Open77.exports.call(...):await()`. Unless a section says otherwise, the player must have a loaded character.

## `listJobCatalog`

Returns a copy of the configured job catalog.

**Configured values:** `unemployed` (grade `0`), `police` (grades `0`, `1`,
`2`), and `fixer` (grades `0`, `1`). Extend them in `Config.jobs`.

```lua
--- Export signature: listJobCatalog()
---@return table<string, table> catalog Defensive copy of `Config.jobs`; empty when unconfigured.

local catalog = Open77.exports.call("bt_core", "listJobCatalog"):await()
```

<ResponseField name="catalog" type="object&lt;string, JobDefinition&gt;" required>
  Defensive copy keyed by `jobKey`; empty when no jobs are configured.
</ResponseField>

<Expandable title="Show JobDefinition fields">
  <ResponseField name="label" type="string" required>Display label.</ResponseField>
  <ResponseField name="category" type="string" required>Domain category such as `civil`, `law`, or `illegal`.</ResponseField>
  <ResponseField name="isIllegal" type="boolean | nil">Optional illegal-job flag.</ResponseField>
  <ResponseField name="grades" type="object&lt;integer, GradeDefinition&gt;" required>Grades indexed from `0`; each contains `label`, `salary`, and `salaryAccount`.</ResponseField>
</Expandable>

## `getJobs`

Returns every character job with its resolved grade.

```lua
--- Export signature: getJobs(playerId)
---@param playerId integer Runtime player identifier. An unloaded character receives the documented fallback.
---@return table[] jobs Resolved held jobs; empty when the character is unavailable.

local jobs = Open77.exports.call("bt_core", "getJobs", playerId):await()
```

<ResponseField name="jobs" type="JobSummary[]" required>
  Resolved held jobs; empty when the character is unavailable.
</ResponseField>

<Expandable title="Show JobSummary fields">
  <ResponseField name="key" type="string" required>Configured job key.</ResponseField>
  <ResponseField name="label" type="string" required>Display label.</ResponseField>
  <ResponseField name="category" type="string" required>Configured category; defaults to `civil`.</ResponseField>
  <ResponseField name="isIllegal" type="boolean" required>Whether the job is marked illegal.</ResponseField>
  <ResponseField name="grade" type="integer" required>Held configured grade.</ResponseField>
  <ResponseField name="gradeLabel" type="string" required>Display label for that grade.</ResponseField>
  <ResponseField name="salary" type="integer" required>Configured salary.</ResponseField>
  <ResponseField name="salaryAccount" type="string" required>Destination account.</ResponseField>
  <ResponseField name="isPrimary" type="boolean" required>Whether this is the primary held job.</ResponseField>
</Expandable>

## `hasJob`

Returns whether the character holds a job.

**Parameters:** `jobKey` accepts a key from `Config.jobs`: `unemployed`,
`police`, or `fixer` by default.

```lua
--- Export signature: hasJob(playerId, jobKey)
---@param playerId integer Runtime player identifier. An unloaded character receives the documented fallback.
---@param jobKey string Configured job key; shipped values are `unemployed`, `police`, and `fixer`.
---@return boolean hasJob `true` when the configured job is held; otherwise `false`.

local employed = Open77.exports.call("bt_core", "hasJob", playerId, "police"):await()
```

## `addJob`

Assigns a configured job and an optional grade.

**Parameters:** `jobKey` accepts `unemployed`, `police`, or `fixer` by default.
Optional `grade` defaults to `0`; available grades are `0` for `unemployed`,
`0` to `2` for `police`, and `0` to `1` for `fixer`. Extend these values in
`Config.jobs`.

```lua
--- Export signature: addJob(playerId, jobKey, grade)
---@param playerId integer Runtime player identifier. The character must be loaded for this mutation.
---@param jobKey string Configured job key; shipped values are `unemployed`, `police`, and `fixer`.
---@param grade? integer Optional grade; defaults to `0` and must exist in `Config.jobs[jobKey].grades`.
---@return boolean success `true` when assigned; `false` if unavailable, already held, or not configured at that grade.

local ok = Open77.exports.call("bt_core", "addJob", playerId, "police", 0):await()
```

## `removeJob`

Removes a job from the character.

**Parameters:** `jobKey` must be one of the character's assigned jobs. Default
configured keys are `unemployed`, `police`, and `fixer`.

```lua
--- Export signature: removeJob(playerId, jobKey)
---@param playerId integer Runtime player identifier. The character must be loaded for this mutation.
---@param jobKey string Key of a job currently held by the character.
---@return boolean success `true` when removed; `false` when unavailable or not held.

local ok = Open77.exports.call("bt_core", "removeJob", playerId, "police"):await()
```

## `setJobGrade`

Updates the grade of an assigned job.

**Parameters:** `jobKey` must be assigned. `grade` accepts `0` for
`unemployed`, `0` to `2` for `police`, or `0` to `1` for `fixer` by default.

```lua
--- Export signature: setJobGrade(playerId, jobKey, grade)
---@param playerId integer Runtime player identifier. The character must be loaded for this mutation.
---@param jobKey string Key of a job currently held by the character.
---@param grade integer Configured grade: `0` for `unemployed`, `0..2` for `police`, or `0..1` for `fixer` by default; no default is applied by this export.
---@return boolean success `true` when updated; `false` when the job is not held or the grade is not configured.

local ok = Open77.exports.call("bt_core", "setJobGrade", playerId, "police", 1):await()
```

## `setPrimaryJob`

Marks an assigned job as primary.

**Parameters:** `jobKey` must be one of the character's assigned jobs. Default
configured keys are `unemployed`, `police`, and `fixer`.

```lua
--- Export signature: setPrimaryJob(playerId, jobKey)
---@param playerId integer Runtime player identifier. The character must be loaded for this mutation.
---@param jobKey string Key of a job currently held by the character.
---@return boolean success `true` when updated; `false` when the job is not held.

local ok = Open77.exports.call("bt_core", "setPrimaryJob", playerId, "police"):await()
```
