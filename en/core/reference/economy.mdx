Call these server exports with `Open77.exports.call(...):await()`. Unless a section says otherwise, the player must have a loaded character.

## `getEddies`

Returns the cash balance.

```lua
--- Export signature: getEddies(playerId)
---@param playerId integer Runtime player identifier. An unloaded character receives the documented fallback.
---@return integer balance Current balance, or `0` when unavailable or invalid.

local eddies = Open77.exports.call("bt_core", "getEddies", playerId):await()
```

## `setEddies`

Sets the cash balance and records the movement.

**Parameters:** `amount` is rounded down and clamped to `0`; optional `reason`
defaults to no audit label.

```lua
--- Export signature: setEddies(playerId, amount, reason)
---@param playerId integer Runtime player identifier. The character must be loaded for this mutation.
---@param amount number Number rounded down and then clamped to `0`; no default.
---@param reason? string Optional audit label; defaults to `nil`.
---@return boolean success `true` when updated; `false` when the character is unavailable or any supplied key/value is invalid.

local ok = Open77.exports.call("bt_core", "setEddies", playerId, 500, "admin_adjustment"):await()
```

## `getOther`

Returns a custom currency balance.

**Parameters:** `key` is extensible, starts with a letter, then contains letters,
digits, or `_`, with at most 32 characters. Examples: `black`, `capsule`.

```lua
--- Export signature: getOther(playerId, key)
---@param playerId integer Runtime player identifier. An unloaded character receives the documented fallback.
---@param key string Custom currency key: letter first, then letters, digits, or `_`; 32 characters maximum.
---@return integer balance Current balance, or `0` when unavailable or invalid.

local balance = Open77.exports.call("bt_core", "getOther", playerId, "capsule"):await()
```

## `setOther`

Sets a custom currency balance.

**Parameters:** `key` follows the format documented in

`0`; optional `reason` has no default label.

```lua
--- Export signature: setOther(playerId, key, amount, reason)
---@param playerId integer Runtime player identifier. The character must be loaded for this mutation.
---@param key string Custom currency key: letter first, then letters, digits, or `_`; 32 characters maximum.
---@param amount number Number rounded down and then clamped to `0`; no default.
---@param reason? string Optional audit label; defaults to `nil`.
---@return boolean success `true` when updated; `false` when the character is unavailable or any supplied key/value is invalid.
```
