Call these server exports with `Open77.exports.call(...):await()`. Unless a section says otherwise, the player must have a loaded character.

## `isReady`

Returns whether the player's character is loaded in memory.

```lua
--- isReady(playerId)
---@param playerId integer Runtime player identifier. An unloaded character receives the documented fallback.
---@return boolean ready `true` when the character is loaded; otherwise `false`.

local ready = Open77.exports.call("bt_core", "isReady", playerId):await()
```

## `getUserId`

--- getUserId(playerId)
---@param playerId integer Runtime player identifier. An unloaded character receives the documented fallback.
---@return string? userId Persistent Open2077 user identifier, or `nil` when unavailable.

## `setFirstname`

Updates the loaded character's first name.

**Parameters:** `value` is a non-empty string of at most 32 characters.

```lua
--- setFirstname(playerId, value)
---@param playerId integer Runtime player identifier. The character must be loaded for this mutation.
---@param value string Non-empty first name, limited to 32 characters.
---@return boolean success `true` when accepted; `false` when the character is unavailable or the value is invalid.

local ok = Open77.exports.call("bt_core", "setFirstname", playerId, "V"):await()
```
