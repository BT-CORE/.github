This site is the documentation portal for the complete BT CORE ecosystem, not
only for `bt_core`. Each resource receives its own installation, configuration,
client API and server API pages when its release is ready.

<Warning>
`Preview` and `pre-release` entries describe work in progress. Their presence in
this catalog is not a promise that a downloadable release already exists.
</Warning>

## Foundation

| Resource | Status | Purpose |
| --- | --- | --- |
| `bt_core` | Preview `0.8.3` | Character identity, persistence, economy, inventory, jobs, vehicles and the shared public contracts. |
| `bt_lib` | Pre-release | Shared client/server helpers for entities, vectors, WebUI, exports and readiness. |

Internal test resources are intentionally excluded. Resources can be added,
renamed or removed before release; this list follows the actual publication
roadmap rather than the contents of a development folder.
</Note>

## Documentation required for a release

Every published resource must add all of the following to this portal:

- purpose, status, version and dependency versions;
- installation, load order, configuration and migration steps;
- separate **client exports** and **server exports** references;
- parameters, return values, nested data structures, failure codes and permissions;
- executable examples and known limitations.
