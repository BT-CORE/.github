Import the module in a client script:

```lua
local BT = assert(require("@bt_lib"))
local vectors = BT.vectors
```

The module runs in the importing resource's VM, so these helpers need no permission.

Headings are in degrees, where `0` is north (`+y`) and angles grow clockwise.
This is the same convention as `Open77.character`.

## `vectors.distance2D`

<Badge color="blue" size="sm" shape="pill" stroke>CLIENT</Badge>

Returns the horizontal distance between two points, ignoring Z.

### Inputs

<ParamField body="a" type="Vec2" required>
  First point.

  <Expandable title="Show Vec2 fields">
    <ParamField body="x" type="number" required>
      World X coordinate.
    </ParamField>
    <ParamField body="y" type="number" required>
      World Y coordinate.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="b" type="Vec2" required>
  Second point.

  <Expandable title="Show Vec2 fields">
    <ParamField body="x" type="number" required>
      World X coordinate.
    </ParamField>
    <ParamField body="y" type="number" required>
      World Y coordinate.
    </ParamField>
  </Expandable>
</ParamField>

### Example

```lua

local meters = vectors.distance2D(a, b)
```

### Returns

<ResponseField name="distance" type="number" required>
  Distance in meters.
</ResponseField>

## `vectors.distanceSq`

<Badge color="blue" size="sm" shape="pill" stroke>CLIENT</Badge>

Returns the squared distance between two points, for cheap comparison against a squared threshold. `z` is optional on each point: a missing `z` reuses the other point's `z`, so two points without `z` give a 2D distance.

### Inputs

<ParamField body="a" type="Vec3 | nil" required>
  First point. Accepts `nil`.

  <Expandable title="Show Vec3 fields">
    <ParamField body="x" type="number" required>
      World X coordinate.
    </ParamField>
    <ParamField body="y" type="number" required>
      World Y coordinate.
    </ParamField>
    <ParamField body="z" type="number" required>
      World Z coordinate.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="b" type="Vec3 | nil" required>
  Second point. Accepts `nil`.

  <Expandable title="Show Vec3 fields">
    <ParamField body="x" type="number" required>
      World X coordinate.
    </ParamField>
    <ParamField body="y" type="number" required>
      World Y coordinate.
    </ParamField>
    <ParamField body="z" type="number" required>
      World Z coordinate.
    </ParamField>
  </Expandable>
</ParamField>

### Example

```lua
--- vectors.distanceSq(a, b)

local near = vectors.distanceSq(playerPosition, target) <= 25.0
```

### Returns

<ResponseField name="distanceSquared" type="number" required>
  Squared distance in square meters. `math.huge` when either point is `nil`.
</ResponseField>

## `vectors.within3D`

<Badge color="blue" size="sm" shape="pill" stroke>CLIENT</Badge>

Tells whether two points are within a distance, without computing a square root.

### Inputs

<ParamField body="a" type="Vec3 | nil" required>
  First point. Accepts `nil`.

  <Expandable title="Show Vec3 fields">
    <ParamField body="x" type="number" required>
      World X coordinate.
    </ParamField>
    <ParamField body="y" type="number" required>
      World Y coordinate.
    </ParamField>
    <ParamField body="z" type="number" required>
      World Z coordinate.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="b" type="Vec3 | nil" required>
  Second point. Accepts `nil`.

  <Expandable title="Show Vec3 fields">
    <ParamField body="x" type="number" required>
      World X coordinate.
    </ParamField>
    <ParamField body="y" type="number" required>
      World Y coordinate.
    </ParamField>
    <ParamField body="z" type="number" required>
      World Z coordinate.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="maxDistance" type="number" required>
  Maximum distance in meters.
</ParamField>

### Example

```lua
--- vectors.within3D(a, b, maxDistance)

local close = vectors.within3D(playerPosition, shopPosition, 3.0)
```

### Returns

<ResponseField name="within" type="boolean" required>
  `true` when the points are at most `maxDistance` apart. `false` when either point is `nil`.
</ResponseField>

## `vectors.atan2`

<Badge color="blue" size="sm" shape="pill" stroke>CLIENT</Badge>

Two-argument arctangent. It exists because `math.atan(y, x)` is not portable in this runtime.

### Inputs

<ParamField body="y" type="number" required>
  Y component.
</ParamField>

<ParamField body="x" type="number" required>
  X component.
</ParamField>

### Example

```lua
--- vectors.atan2(y, x)

local radians = vectors.atan2(1, 1)
```

### Returns

<ResponseField name="angle" type="number" required>
  Angle in radians. `0` when both components are `0`.
</ResponseField>
