`bt_lib` removes duplicated low-level helpers from BT CORE resources while
keeping business logic in the resource that owns it. It has two parts:

- **client modules**, imported with `require("@bt_lib")`, for rays and ground
  clearance, nearby entities, vectors, the local character position, eddies
  formatting and a full-screen WebUI surface;
- **server exports**, called with `Open77.exports.call("bt_lib", ...)`, for
  resource calls, notifications, character readiness, zone lookup and eddies
  formatting.

## Requirements

- `bt_core >=0.8.1`;
- an Open2077 server compatible with `open77_version ">=0.0.1"`.

`bt_lib` does not require the optional notification package. `notify` returns
`nil, "notifications_unavailable"` when the native notification API is missing.

## Install

Place the release at `resources/bt_lib/`, then add `bt_lib` to `resources.load`
after `bt_core`. Merge the entry; do not replace the rest of your file.

```jsonc
{
  "resources": {
    "load": [
      "open77_weapons",
      "bt_inventory",
      "bt_core",
      "bt_lib"
    ]
  }
}
```

Restart the dedicated server after changing `server.jsonc`. A resource that uses
the client modules declares the dependency in its manifest:

```lua
dependency "bt_lib >=0.1.0"
```

## Verify the installation

At startup the server prints:

```text
[bt_lib] ready (callResource, notify, requireCharacterReady, zoneLookup, formatEddies)
```

## Permissions

`bt_lib` declares exactly these manifest permissions:

- `local.events`;
- `network.events`.

Client modules run in the importing resource's VM with **that resource's**
permissions, never with those of `bt_lib`. A resource that calls `raycast` or
`entities` declares `world.query`; one that calls `entities.nearestOwnProp`
declares `world.props`.

## Known limits

- `callResource` makes `bt_lib` the invoking resource. Call an export directly
  when it authorizes or audits by `GetInvokingResource()`.
- `entities.TRAFFIC_LIGHT_HASHES` was collected in game and is not exhaustive.
  No documented API exposes a traffic light's color state.
- `raycast.bestHeading` finds the most open direction. It does not detect the
  traffic direction.
- `webui.create` uses a `1920` by `1080` logical surface unless you pass
  `width` and `height`.
