Import the module in a client script:

```lua
local BT = assert(require("@bt_lib"))
local raycast = BT.raycast
```

The module runs in the importing resource's VM, so the calling resource must declare the `world.query` permission. `lookAt` with cursor coordinates also needs `input.actions`. `bt_lib` itself holds no permission.

## `raycast.cast`

<Badge color="blue" size="sm" shape="pill" stroke>CLIENT</Badge>

Casts a raw world ray between two points. It is the single entry point so that resources do not call `Open77.world.raycast` directly.

**Precondition:** The calling resource declares the `world.query` permission. A live game instance is required.

### Inputs

<ParamField body="from" type="Vec3" required>
  Ray start.

  <Expandable title="Show Vec3 fields">
    <ParamField body="x" type="number" required>
      World X coordinate.
    </ParamField>
    <ParamField body="y" type="number" required>
      World Y coordinate.
    </ParamField>
    <ParamField body="z" type="number" required>
      World Z coordinate.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="to" type="Vec3" required>
  Ray end.

  <Expandable title="Show Vec3 fields">
    <ParamField body="x" type="number" required>
      World X coordinate.
    </ParamField>
    <ParamField body="y" type="number" required>
      World Y coordinate.
    </ParamField>
    <ParamField body="z" type="number" required>
      World Z coordinate.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="options" type="RaycastOptions" default="nil">
  Optional. Collision groups to include. When omitted, both groups are used.

  <Expandable title="Show RaycastOptions fields">
    <ParamField body="static" type="boolean" default="true">
      Optional. Include static world geometry.
    </ParamField>
    <ParamField body="dynamic" type="boolean" default="true">
      Optional. Include dynamic objects, vehicles and NPCs.
    </ParamField>
  </Expandable>
</ParamField>

### Example

```lua

local origin = Open77.character.state().position
local ray, reason = raycast.cast(origin, { x = origin.x + 20, y = origin.y, z = origin.z })
```

## `raycast.hasClearance`

**Precondition:** The calling resource declares the `world.query` permission.

<ParamField body="y" type="number" required>

</ParamField>

</ParamField>

</ParamField>

  <Expandable title="Show ClearanceOptions fields">

    </ParamField>
    <ParamField body="dirs" type="Vec2[]" default="{ +x, -x, +y, -y }">
      Optional. Ray directions. Defaults to the four cardinal directions.

        </ParamField>
        <ParamField body="y" type="number" required>
          World Y coordinate.

      </Expandable>
    </ParamField>
    <ParamField body="rayOptions" type="RaycastOptions" default="nil">

      <Expandable title="Show RaycastOptions fields">
        <ParamField body="static" type="boolean" default="true">
          Optional. Include static world geometry.
        </ParamField>
        <ParamField body="dynamic" type="boolean" default="true">
          Optional. Include dynamic objects, vehicles and NPCs.
        </ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

### Example

```lua
--- raycast.hasClearance(x, y, z, length, options)
```

  `true` when no ray hits an obstacle. `false` when a ray hits, a ray cannot run, or `Open77.world.raycast` is unavailable.
</ResponseField>

## `raycast.hasFootprintClearance`

<Badge color="blue" size="sm" shape="pill" stroke>CLIENT</Badge>

Budgeted variant of `hasClearance`. It probes the four sides of a footprint at one or several heights, and stops as soon as a ray hits something or the ray budget is spent. The cost is bounded by construction.

**Precondition:** The calling resource declares the `world.query` permission.

### Inputs

<ParamField body="x" type="number" required>
  World X coordinate.
</ParamField>

<ParamField body="y" type="number" required>
  World Y coordinate.
</ParamField>

<ParamField body="z" type="number" required>
  Ground height.
</ParamField>

<ParamField body="footprint" type="ClearanceFootprint" default="nil">
  Optional. Footprint half sizes. When omitted, `1.5` by `1.5` is used.

  <Expandable title="Show ClearanceFootprint fields">
    <ParamField body="halfLengthM" type="number" default="1.5">
      Optional. Half length of the footprint in meters.
    </ParamField>
    <ParamField body="halfWidthM" type="number" default="1.5">
      Optional. Half width of the footprint in meters.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="rayHeightsM" type="number[]" default="{ 1.0 }">
  Optional. Ray heights above the ground, in meters.
</ParamField>

<ParamField body="maxRays" type="integer" default="4">
  Optional. Maximum number of rays in total.
</ParamField>

### Example

```lua
--- raycast.hasFootprintClearance(x, y, z, footprint, rayHeightsM, maxRays)

local clear = raycast.hasFootprintClearance(x, y, z, { halfLengthM = 2.5, halfWidthM = 1.2 }, { 0.5, 1.2 }, 8)
```

### Returns

<ResponseField name="clear" type="boolean" required>
  `false` when a ray hits an obstacle. `true` when nothing was hit, when the ray budget is spent, or when `Open77.world.raycast` is unavailable.
</ResponseField>

## `raycast.footprintGroundClear`

<Badge color="blue" size="sm" shape="pill" stroke>CLIENT</Badge>

Most complete clearance check. It samples a 3x3 grid oriented by the heading, measures the ground under each of the nine points, rejects a point that differs from the center height by more than `maxGroundDeltaM`, then tests horizontal clearance along both grid axes. It rules out walls and voids without banning sloped roads.

**Precondition:** The calling resource declares the `world.query` permission.

### Inputs

<ParamField body="x" type="number" required>
  World X coordinate.
</ParamField>

<ParamField body="y" type="number" required>
  World Y coordinate.
</ParamField>

<ParamField body="z" type="number" required>
  Ground height at the center.
</ParamField>

<ParamField body="yaw" type="number" default="0">
  Optional. Heading in degrees. When omitted, `0` is used.
</ParamField>

<ParamField body="footprint" type="GroundFootprint" default="nil">
  Optional. Footprint sizes and limits. When omitted, the defaults listed in the type apply.

  <Expandable title="Show GroundFootprint fields">
    <ParamField body="halfLengthM" type="number" default="3.0">
      Optional. Half length of the footprint in meters.
    </ParamField>
    <ParamField body="halfWidthM" type="number" default="1.35">
      Optional. Half width of the footprint in meters.
    </ParamField>
    <ParamField body="maxGroundDeltaM" type="number" default="1.5">
      Optional. Maximum ground height difference from the center, in meters.
    </ParamField>
    <ParamField body="rayHeightsM" type="number[]" default="{ 0.4, 1.25 }">
      Optional. Horizontal ray heights above the ground, in meters.
    </ParamField>
  </Expandable>
</ParamField>

### Example

```lua
--- raycast.footprintGroundClear(x, y, z, yaw, footprint)

local ok = raycast.footprintGroundClear(x, y, z, heading, { halfLengthM = 2.4, halfWidthM = 1.1 })
```

### Returns

<ResponseField name="clear" type="boolean" required>
  `true` when the whole footprint is on usable ground with clear space. `false` otherwise, including when a ground sample is missing or `Open77.world.raycast` is unavailable.
</ResponseField>

## `raycast.classifyMaterial`

<Badge color="blue" size="sm" shape="pill" stroke>CLIENT</Badge>

Returns the ground category of a raw material name. The built-in table covers `stone`, `sand`, `carpet`, `ceramic`, `tiles`, `metal`, `concrete`, `metal_car` and `asphalt` physical materials.

### Inputs

<ParamField body="material" type="string" default="nil">

</ParamField>

### Example

```lua

```

### Returns

<ResponseField name="category" type="'rock' | 'sand' | 'inside' | 'sidewalk' | 'road' | nil" post={["optional"]}>
  Ground category. `nil` when the material is unknown or not a string.
</ResponseField>

## `raycast.lookAt`

<Badge color="blue" size="sm" shape="pill" stroke>CLIENT</Badge>

Casts a camera ray through normalized viewport coordinates and identifies the aimed entity. The result is UI observation, not authorization: the server must validate any action independently.

**Precondition:** The calling resource declares the `world.query` permission. Aiming with the cursor coordinates from `Open77.input.cursor` also requires `input.actions`.

### Inputs

<ParamField body="maxDistance" type="number" default="12">
  Optional. Maximum distance in meters.
</ParamField>

<ParamField body="options" type="ScreenRaycastOptions" default="nil">
  Optional. Collision groups to include. At least one group must stay enabled.

  <Expandable title="Show ScreenRaycastOptions fields">
    <ParamField body="static" type="boolean" default="true">
      Optional. Include static world geometry.
    </ParamField>
    <ParamField body="dynamic" type="boolean" default="true">
      Optional. Include dynamic objects, vehicles and NPCs.
    </ParamField>
    <ParamField body="self" type="boolean" default="false">
      Optional. Include the visible local body (F7 body picking).
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="viewX" type="number" default="0.5">
  Optional. Normalized horizontal viewport coordinate from `0` to `1`.
</ParamField>

<ParamField body="viewY" type="number" default="0.5">
  Optional. Normalized vertical viewport coordinate from `0` to `1`.
</ParamField>

### Example

```lua
--- raycast.lookAt(maxDistance, options, viewX, viewY)

local hit, reason = raycast.lookAt(8)
if hit and hit.target then print(hit.target.kind) end
```

## `raycast.bestHeading`

<Badge color="blue" size="sm" shape="pill" stroke>CLIENT</Badge>

Finds the most open direction around a point. It traces a line on each side of the point for evenly spaced headings and returns the heading whose line goes the farthest without hitting anything. It does not detect the traffic direction, only which side is more open.

**Precondition:** The calling resource declares the `world.query` permission.

### Inputs

<ParamField body="position" type="Vec3" required>
  Point to probe around.

  <Expandable title="Show Vec3 fields">
    <ParamField body="x" type="number" required>
      World X coordinate.
    </ParamField>
    <ParamField body="y" type="number" required>
      World Y coordinate.
    </ParamField>
    <ParamField body="z" type="number" required>
      World Z coordinate.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="options" type="BestHeadingOptions" default="nil">
  Optional. Probe settings. When omitted, the defaults listed in the type apply.

  <Expandable title="Show BestHeadingOptions fields">
    <ParamField body="count" type="integer" default="8">
      Optional. Number of evenly spaced headings to test.
    </ParamField>
    <ParamField body="checkDistance" type="number" default="4.0">
      Optional. Half length of each probe line in meters.
    </ParamField>
    <ParamField body="heightM" type="number" default="1.0">
      Optional. Probe height above the point in meters.
    </ParamField>
  </Expandable>
</ParamField>

### Example

```lua
--- raycast.bestHeading(position, options)

local heading = raycast.bestHeading(position, { count = 12 })
```
