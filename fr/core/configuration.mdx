Tous les réglages vivent dans `server/config.lua`. Ce fichier est chargé côté
serveur : ne pas déplacer de secret ou de configuration autoritaire dans du
code client ou partagé.

## Valeurs par défaut

| Réglage | Valeur | Rôle |
| --- | --- | --- |
| `Config.defaultSpawn` | `381.358826, -2401.794189, 181.988541` | Position et orientation de première arrivée. |
| `Config.spawn.joinRetryMs` | `250` | Délai entre les contrôles de placement. |
| `Config.spawn.joinTimeoutMs` | `30000` | Attente maximale du placement initial. |
| `Config.death.respawnDelayMs` | `4000` | Délai de respawn après une mort naturelle. |
| `Config.death.health` | `1.0` | Ratio de santé demandé au respawn. |
| `Config.death.graceMs` | `5000` | Période de grâce après respawn. |
| `Config.vitals.friendlyFire` | `true` | Active les dégâts alliés dans la politique serveur. |
| `Config.vitals.damageMultiplier` | `1.0` | Multiplicateur global des dégâts côté serveur. |
| `Config.vitals.sprint.drainPerSecond` | `12.0` | Consommation d'endurance ciblée pendant le sprint. |
| `Config.vitals.sprint.tickMs` | `500` | Intervalle autoritaire de consommation. |
| `Config.vitals.sprint.heartbeatTimeoutMs` | `4000` | Arrête la consommation si les signaux client cessent. |
| `Config.jobsPayIntervalMs` | `600000` | Fréquence de la paie automatique en millisecondes. |
| `Config.characterSlots` | `1` | Nombre de personnages par compte. |
| `Config.language` | `"en"` | Locale active ; une valeur inconnue revient à l'anglais. |

## Marque et onboarding

`Config.brand` contrôle le nom, le badge et le slogan transmis au HUD.

`Config.onboarding` contrôle :

- `openDelayMs` : délai avant ouverture, `0` par défaut ;
- `rpYearOffset` : décalage du calendrier RP, `51` par défaut ;
- `minAge` et `maxAge` : âge accepté, de `18` à `100` ans ;
- `cinematicAnchor` : position autoritaire utilisée par la caméra d'onboarding.

Le formulaire accepte `male` et `female` pour le sexe, puis `corpo`,
`streetkid` ou `nomad` pour le lifepath.

## Combat et constantes vitales

`Config.vitals` définit la politique serveur. Le client signale uniquement si
le personnage natif est en train de sprinter. Le serveur possède les mutations
d'endurance, interrompt sa régénération pendant le sprint et restaure son état
précédent à l'arrêt du sprint ou de la ressource.

La boucle retire uniquement la consommation qui n'a pas déjà été appliquée
nativement pendant le même intervalle. Cela évite un double coût sur les builds
qui consomment déjà l'endurance. Garder `heartbeatTimeoutMs` supérieur au
heartbeat actif d'une seconde.

## Métiers

`Config.jobs` est le catalogue autoritaire. Chaque métier définit un libellé,
une catégorie et des grades. Chaque grade contient son libellé, son salaire et
le compte de versement.

Le catalogue fourni contient :

- `unemployed`, payé `0` sur `cash` ;
- `police`, grades `0` à `2`, payé sur `bank` ;
- `fixer`, grades `0` à `1`, payé sur le compte personnalisé `black`.

Pour ajouter un métier, choisir une clé stable et vérifier que chaque compte de
salaire est `cash`, `bank` ou un compte créé au préalable avec `addOther`.

## Garages

`Config.garages` est le catalogue autoritaire des garages. La clé `default`
doit toujours exister : toute clé retirée ou inconnue revient vers elle.

```lua
Config.garages = {
    default = {
        label = "Garage",
        position = { x = 396.0, y = -2390.0, z = 181.99, heading = 90.0 },
    },
}
```

## Langues

Les locales prises en charge sont `en` et `fr`, dans `lang/en.lua` et
`lang/fr.lua`. Ajouter chaque nouveau texte visible dans les deux fichiers. La
logique Lua et les WebUI ne doivent pas contenir de traduction codée en dur.
