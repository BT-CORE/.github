Appeler ces exports serveur avec `Open77.exports.call(...):await()`. Sauf indication contraire, le joueur doit posséder un personnage chargé.

## `isReady`

Indique si le personnage du joueur est chargé en mémoire.

```lua
--- Signature de l'export : isReady(playerId)
---@param playerId integer Identifiant runtime du joueur. Un personnage non chargé reçoit la valeur de repli documentée.
---@return boolean ready `true` si le personnage est chargé ; sinon `false`.

local ready = Open77.exports.call("bt_core", "isReady", playerId):await()
```

## `setFirstname`

Modifie le prénom du personnage chargé.

**Paramètres :** `value` est une chaîne non vide de 32 caractères maximum.

```lua
--- Signature de l'export : setFirstname(playerId, value)
---@param playerId integer Identifiant runtime du joueur. Le personnage doit être chargé pour cette modification.
---@param value string Prénom non vide, limité à 32 caractères.
---@return boolean success `true` si la valeur est acceptée ; `false` si le personnage est indisponible ou la valeur invalide.

local ok = Open77.exports.call("bt_core", "setFirstname", playerId, "V"):await()
```

```lua

---@param playerId integer Identifiant runtime du joueur. Le personnage doit être chargé pour cette modification.
---@param isoDate string Date respectant `YYYY-MM-DD` ; aucune valeur par défaut.
---@return boolean success `true` si la valeur est acceptée ; `false` si le personnage est indisponible ou la valeur invalide.

local ok = Open77.exports.call("bt_core", "setDateOfBirth", playerId, "2045-06-12"):await()
```

## `setSex`

Modifie la valeur de sexe du personnage chargé.

**Paramètres :** `value` accepte toute chaîne de 16 caractères maximum.
L'onboarding fournit actuellement `male` ou `female`. Aucune valeur par défaut
n'est appliquée.

```lua
--- Signature de l'export : setSex(playerId, value)
---@param playerId integer Identifiant runtime du joueur. Le personnage doit être chargé pour cette modification.
---@param value string Chaîne de 16 caractères maximum ; l'onboarding utilise `male` ou `female` ; aucun défaut.
---@return boolean success `true` si la valeur est acceptée ; `false` si le personnage est indisponible ou la valeur invalide.

local ok = Open77.exports.call("bt_core", "setSex", playerId, "female"):await()
```

```lua

---@param playerId integer Identifiant runtime du joueur. Le personnage doit être chargé pour cette modification.
---@param value 'corpo'|'streetkid'|'nomad' Origine canonique ; aucune valeur par défaut.
---@return boolean success `true` si la valeur est acceptée ; `false` si le personnage est indisponible ou la valeur invalide.

local ok = Open77.exports.call("bt_core", "setLifepath", playerId, "nomad"):await()
```
