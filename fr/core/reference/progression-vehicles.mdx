title: "Progression"
description: "Lire et modifier l'expérience persistante du personnage."

---

Appeler ces **exports serveur** avec `Open77.exports.call(...):await()`. Le
personnage doit être chargé.

## `getXp`

Retourne les points d'expérience du personnage.

```lua
--- Signature : getXp(playerId)
---@param playerId integer Identifiant runtime du joueur.
---@return integer xp XP courant, ou 0 si le personnage est indisponible.
local xp = Open77.exports.call("bt_core", "getXp", playerId):await()
```

## `setXp`

Fixe le total. `amount` est arrondi à l'entier inférieur puis limité à `0`.

```lua
--- Signature : setXp(playerId, amount)
---@param playerId integer Identifiant runtime du joueur.
---@param amount number Valeur arrondie puis limitée à 0.
---@return boolean success Faux si le personnage ou la valeur est invalide.
local ok = Open77.exports.call("bt_core", "setXp", playerId, 1000):await()
```

## `addXp`

Ajoute un montant positif ou négatif non nul. Le total final ne peut pas être négatif.

```lua
--- Signature : addXp(playerId, amount)
---@param playerId integer Identifiant runtime du joueur.
---@param amount number Delta non nul.
---@return boolean success Faux si le personnage ou le delta est invalide.
local ok = Open77.exports.call("bt_core", "addXp", playerId, 25):await()
```
