Ces exports existent uniquement dans un **script client**. Les appeler avec
`Open77.exports.call(...):await()` sans `playerId`.

## `isReady`

Indique si le client local a reçu le payload autoritaire `bt_core:ready` et
possède actuellement un instantané de personnage.

```lua
local ready = Open77.exports.call("bt_core", "isReady"):await()
if not ready then return end
```

<ResponseField name="ready" type="boolean" required>
  `true` après `bt_core:ready` ; repasse à `false` à la fin de la session Open2077.
</ResponseField>

## `snapshot`

Retourne les données du personnage capturées à la réception de `bt_core:ready`.

```lua
local player = Open77.exports.call("bt_core", "snapshot"):await()
if not player then return end

print(("Bienvenue %s %s"):format(player.firstname, player.lastname))
```

<ResponseField name="snapshot" type="CharacterSnapshot | nil">
  Le dernier instantané de disponibilité, ou `nil` avant celle-ci et après la
  fin de session.
</ResponseField>

  <ResponseField name="phoneNumber" type="string | nil">Numéro de téléphone persistant généré.</ResponseField>

</Expandable>

<Warning>
L'instantané client n'est pas actualisé après chaque mutation serveur. Le traiter
comme une donnée d'initialisation en lecture seule. Pour une valeur fraîche,
appeler l'export serveur concerné ou `snapshot(playerId)` depuis un script serveur.
</Warning>
