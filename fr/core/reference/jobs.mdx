Appeler ces exports serveur avec `Open77.exports.call(...):await()`. Sauf indication contraire, le joueur doit posséder un personnage chargé.

## `listJobCatalog`

Retourne une copie du catalogue des métiers configurés.

**Valeurs configurées :** `unemployed` (grade `0`), `police` (grades `0`, `1`,
`2`) et `fixer` (grades `0`, `1`). Elles sont extensibles dans `Config.jobs`.

```lua
--- listJobCatalog()
---@return table<string, table> catalog Copie défensive de `Config.jobs` ; vide sans configuration.

local catalog = Open77.exports.call("bt_core", "listJobCatalog"):await()
```

<ResponseField name="catalog" type="object&lt;string, JobDefinition&gt;" required>
  Copie défensive indexée par `jobKey`, vide si aucun métier n'est configuré.
</ResponseField>

<Expandable title="Afficher les champs de JobDefinition">
  <ResponseField name="label" type="string" required>Libellé affiché.</ResponseField>
  <ResponseField name="category" type="string" required>Catégorie comme `civil`, `law` ou `illegal`.</ResponseField>
  <ResponseField name="isIllegal" type="boolean | nil">Drapeau facultatif de métier illégal.</ResponseField>
  <ResponseField name="grades" type="object&lt;integer, GradeDefinition&gt;" required>Grades indexés depuis `0`, chacun avec `label`, `salary` et `salaryAccount`.</ResponseField>
</Expandable>

## `getJobs`

Retourne tous les métiers du personnage avec leurs grades résolus.

```lua
--- getJobs(playerId)
---@param playerId integer Identifiant runtime du joueur. Un personnage non chargé reçoit la valeur de repli documentée.
---@return table[] jobs Métiers attribués et résolus ; vide si le personnage est indisponible.

local jobs = Open77.exports.call("bt_core", "getJobs", playerId):await()
```

<ResponseField name="jobs" type="JobSummary[]" required>
  Métiers détenus résolus, ou liste vide si le personnage est indisponible.
</ResponseField>

<Expandable title="Afficher les champs de JobSummary">
  <ResponseField name="key" type="string" required>Clé configurée du métier.</ResponseField>
  <ResponseField name="label" type="string" required>Libellé affiché.</ResponseField>
  <ResponseField name="category" type="string" required>Catégorie configurée, `civil` par défaut.</ResponseField>
  <ResponseField name="isIllegal" type="boolean" required>Indique si le métier est illégal.</ResponseField>
  <ResponseField name="grade" type="integer" required>Grade configuré détenu.</ResponseField>
  <ResponseField name="gradeLabel" type="string" required>Libellé du grade.</ResponseField>
  <ResponseField name="salary" type="integer" required>Salaire configuré.</ResponseField>
  <ResponseField name="salaryAccount" type="string" required>Compte de destination.</ResponseField>
  <ResponseField name="isPrimary" type="boolean" required>Indique s'il s'agit du métier principal.</ResponseField>
</Expandable>

## `hasJob`

Indique si le personnage possède un métier.

**Paramètres :** `jobKey` accepte une clé de `Config.jobs` : `unemployed`,
`police` ou `fixer` par défaut.

```lua
--- hasJob(playerId, jobKey)
---@param playerId integer Identifiant runtime du joueur. Un personnage non chargé reçoit la valeur de repli documentée.
---@param jobKey string Clé de métier configurée ; valeurs livrées : `unemployed`, `police` et `fixer`.
---@return boolean hasJob `true` si le métier configuré est attribué ; sinon `false`.

local employed = Open77.exports.call("bt_core", "hasJob", playerId, "police"):await()
```

## `addJob`

Attribue un métier configuré et un grade facultatif.

**Paramètres :** `jobKey` accepte `unemployed`, `police` ou `fixer` par défaut.
`grade`, facultatif, vaut `0` par défaut ; les grades disponibles sont `0` pour
`unemployed`, `0` à `2` pour `police` et `0` à `1` pour `fixer`. Ces valeurs
sont extensibles dans `Config.jobs`.

```lua
--- addJob(playerId, jobKey, grade)
---@param playerId integer Identifiant runtime du joueur. Le personnage doit être chargé pour cette modification.
---@param jobKey string Clé de métier configurée ; valeurs livrées : `unemployed`, `police` et `fixer`.
---@param grade? integer Grade facultatif ; vaut `0` par défaut et doit exister dans `Config.jobs[jobKey].grades`.
---@return boolean success `true` si le métier est attribué ; `false` s'il est indisponible, déjà attribué ou non configuré à ce grade.

local ok = Open77.exports.call("bt_core", "addJob", playerId, "police", 0):await()
```

## `removeJob`

Retire un métier du personnage.

**Paramètres :** `jobKey` doit correspondre à un métier attribué au personnage.
Les clés configurées par défaut sont `unemployed`, `police` et `fixer`.

```lua
--- removeJob(playerId, jobKey)
---@param playerId integer Identifiant runtime du joueur. Le personnage doit être chargé pour cette modification.
---@param jobKey string Clé d'un métier actuellement attribué au personnage.
---@return boolean success `true` si le métier est retiré ; `false` s'il est indisponible ou non attribué.

local ok = Open77.exports.call("bt_core", "removeJob", playerId, "police"):await()
```

## `setJobGrade`

Modifie le grade d'un métier déjà attribué.

**Paramètres :** `jobKey` doit être attribué. `grade` accepte `0` pour
`unemployed`, `0` à `2` pour `police` ou `0` à `1` pour `fixer` par défaut.

```lua
--- setJobGrade(playerId, jobKey, grade)
---@param playerId integer Identifiant runtime du joueur. Le personnage doit être chargé pour cette modification.
---@param jobKey string Clé d'un métier actuellement attribué au personnage.
---@param grade integer Grade configuré : `0` pour `unemployed`, `0..2` pour `police` ou `0..1` pour `fixer` dans la configuration livrée ; cet export n'applique aucune valeur par défaut.
---@return boolean success `true` si le grade est modifié ; `false` si le métier n'est pas attribué ou le grade non configuré.

local ok = Open77.exports.call("bt_core", "setJobGrade", playerId, "police", 1):await()
```

## `setPrimaryJob`

Définit comme principal un métier déjà attribué.

**Paramètres :** `jobKey` doit correspondre à un métier attribué au personnage.
Les clés configurées par défaut sont `unemployed`, `police` et `fixer`.

```lua
--- setPrimaryJob(playerId, jobKey)
---@param playerId integer Identifiant runtime du joueur. Le personnage doit être chargé pour cette modification.
---@param jobKey string Clé d'un métier actuellement attribué au personnage.
---@return boolean success `true` si le métier devient principal ; `false` s'il n'est pas attribué.

local ok = Open77.exports.call("bt_core", "setPrimaryJob", playerId, "police"):await()
```
