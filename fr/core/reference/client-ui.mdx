Ces exports existent uniquement dans un **script client**. La disponibilité, le
spawn et l'onboarding restent autoritaires : un appel `show` ne les contourne pas.

## `hideUI`

Applique le masquage global au HUD personnalisé et au watermark.

```lua
local ok = Open77.exports.call("bt_core", "hideUI"):await()
```

<ResponseField name="success" type="boolean" required>Toujours `true`.</ResponseField>

## `showUI`

Libère le masquage global. Les composants ne redeviennent visibles que si
l'interface de jeu est autorisée et leur masquage individuel est libéré.

```lua
local ok = Open77.exports.call("bt_core", "showUI"):await()
```

<ResponseField name="success" type="boolean" required>Toujours `true`.</ResponseField>

## `hide`

Masque un composant.

<ParamField body="component" type="string" required>
  `hud`, `watermark`, `all` ou `ui`. `all` et `ui` sélectionnent le masquage global.
</ParamField>

```lua
local ok, errorCode = Open77.exports.call("bt_core", "hide", "hud"):await()
```

<ResponseField name="success" type="boolean" required>`false` pour un composant inconnu.</ResponseField>
<ResponseField name="errorCode" type="string | nil">`unknown_ui_component` en cas de rejet.</ResponseField>

## `show`

Libère le masquage individuel d'un composant.

<ParamField body="component" type="string" required>
  `hud`, `watermark`, `all` ou `ui`. `all` et `ui` sélectionnent le masquage global.
</ParamField>

```lua
local ok, errorCode = Open77.exports.call("bt_core", "show", "watermark"):await()
```

<ResponseField name="success" type="boolean" required>`false` pour un composant inconnu.</ResponseField>
<ResponseField name="errorCode" type="string | nil">`unknown_ui_component` en cas de rejet.</ResponseField>

## `isVisible`

Retourne la visibilité effective après les contrôles de disponibilité, spawn,
onboarding, masquage global et masquage individuel.

<ParamField body="component" type="string" required>
  `hud`, `watermark`, `all` ou `ui`. Pour `all`/`ui`, `true` signifie qu'au moins
  un composant public est visible.
</ParamField>

```lua
local visible, errorCode = Open77.exports.call("bt_core", "isVisible", "hud"):await()
```

<ResponseField name="visible" type="boolean | nil">Visibilité effective, ou `nil` pour un composant inconnu.</ResponseField>
<ResponseField name="errorCode" type="string | nil">`unknown_ui_component` en cas de rejet.</ResponseField>

## `uiState`

Retourne toutes les barrières publiques et les visibilités effectives.

```lua
local state = Open77.exports.call("bt_core", "uiState"):await()
if state.allowed and not state.hud then
    print("Le HUD est masqué par une surcharge")
end
```

<ResponseField name="state" type="UIState" required>
  Voir le [contrat UIState](./contracts#uistate).
</ResponseField>
