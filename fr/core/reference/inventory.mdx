Appeler ces exports serveur avec `Open77.exports.call(...):await()`. Sauf indication contraire, le joueur doit posséder un personnage chargé.

## `getItem`

Retourne la quantité persistante d'un objet.

**Paramètres :** `key` commence par une lettre, puis contient des lettres,
chiffres, `_` ou `.`, sur 96 caractères maximum. Utiliser un identifiant objet
TweakDB valide comme `Items.Preset_Lexington_Default`.

```lua
--- Signature de l'export : getItem(playerId, key)
---@param playerId integer Identifiant runtime du joueur. Un personnage non chargé reçoit la valeur de repli documentée.
---@param key string Clé d'objet : une lettre puis lettres, chiffres, `_` ou `.` ; 96 caractères maximum.
---@return integer quantity Quantité enregistrée, ou `0` si l'entrée est indisponible ou invalide.

local quantity = Open77.exports.call("bt_core", "getItem", playerId, "Items.Preset_Lexington_Default"):await()
```

## `setItem`

Fixe la quantité persistante d'un objet.

**Paramètres :** `key` suit le format de
[`FR server-getItem`](#fr-server-getitem). `quantity` est arrondi à l'entier inférieur
et limité à `0` ; `reason`, facultatif, n'a pas de libellé par défaut.

```lua
--- Signature de l'export : setItem(playerId, key, quantity, reason)
---@param playerId integer Identifiant runtime du joueur. Le personnage doit être chargé pour cette modification.
---@param key string Clé d'objet : une lettre puis lettres, chiffres, `_` ou `.` ; 96 caractères maximum.
---@param quantity number Nombre arrondi à l'entier inférieur puis limité à `0` ; aucun défaut.
---@param reason? string Libellé d'audit facultatif ; `nil` par défaut.
---@return boolean success `true` si la mise à jour réussit ; `false` si le personnage est indisponible ou une clé/valeur fournie est invalide.

local ok = Open77.exports.call("bt_core", "setItem", playerId, "Items.Preset_Lexington_Default", 1, "admin_adjustment"):await()
```

## `addItem`

Ajoute une quantité à l'inventaire persistant.

**Paramètres :** `key` suit le format de
[`FR server-getItem`](#fr-server-getitem). `quantity` doit être non nulle et peut être
négative ; `reason`, facultatif, n'a pas de libellé par défaut.

```lua
--- Signature de l'export : addItem(playerId, key, quantity, reason)
---@param playerId integer Identifiant runtime du joueur. Le personnage doit être chargé pour cette modification.
---@param key string Clé d'objet : une lettre puis lettres, chiffres, `_` ou `.` ; 96 caractères maximum.
---@param quantity number Nombre non nul, positif ou négatif ; aucun défaut.
---@param reason? string Libellé d'audit facultatif ; `nil` par défaut.
---@return boolean success `true` si la mise à jour réussit ; `false` si le personnage est indisponible ou une clé/valeur fournie est invalide.

local ok = Open77.exports.call("bt_core", "addItem", playerId, "Items.Preset_Lexington_Default", 1, "ground_pickup"):await()
```

## `removeItem`

Retire une quantité si l'inventaire est suffisant.

**Paramètres :** `key` suit le format de
[`FR server-getItem`](#fr-server-getitem). `quantity` doit être positive et est
arrondie à l'entier inférieur ; `reason`, facultatif, n'a pas de libellé par
défaut.

```lua
--- Signature de l'export : removeItem(playerId, key, quantity, reason)
---@param playerId integer Identifiant runtime du joueur. Le personnage doit être chargé pour cette modification.
---@param key string Clé d'objet : une lettre puis lettres, chiffres, `_` ou `.` ; 96 caractères maximum.
---@param quantity number Nombre positif, arrondi à l'entier inférieur ; aucun défaut.
---@param reason? string Libellé d'audit facultatif ; `nil` par défaut.
---@return boolean success `true` si le retrait réussit ; `false` pour une entrée invalide, un personnage indisponible ou un solde insuffisant.

local ok = Open77.exports.call("bt_core", "removeItem", playerId, "Items.Preset_Lexington_Default", 1, "item_used"):await()
```

## `listItems`

Retourne une copie de l'inventaire persistant.

```lua
--- Signature de l'export : listItems(playerId)
---@param playerId integer Identifiant runtime du joueur. Un personnage non chargé reçoit la valeur de repli documentée.
---@return table<string, integer> items Copie défensive ; vide si le personnage est indisponible.

local items = Open77.exports.call("bt_core", "listItems", playerId):await()
```
