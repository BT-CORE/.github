---
title: "Contrôle d'accès"
description: "Lire les niveaux d'accès et gérer les rôles libres des personnages."
icon: "user-shield"
---

Appeler ces **exports serveur** avec `Open77.exports.call(...):await()`. Le
personnage doit être chargé pour toute mutation.

## `getPermissionLevel`

Retourne le niveau numérique de permission enregistré.

```lua
local level = Open77.exports.call("bt_core", "getPermissionLevel", playerId):await()
```

<ResponseField name="permissionLevel" type="integer" required>
  Niveau enregistré, ou `0` si le personnage est indisponible.
</ResponseField>
## `getRoles`

Retourne les clés libres de rôles staff. Considérer la table comme non modifiable.

```lua
local roles = Open77.exports.call("bt_core", "getRoles", playerId):await()
```

<ResponseField name="roles" type="string[]" required>
  Clés attribuées, ou liste vide si le personnage est indisponible.
</ResponseField>

## `hasRole`

Vérifie si une clé de rôle libre est attribuée. Il n'existe aucune liste prédéfinie.

<ParamField body="playerId" type="integer" required>Identifiant runtime du joueur.</ParamField>
<ParamField body="role" type="string" required>Clé exacte du rôle libre.</ParamField>

```lua
local moderator = Open77.exports.call("bt_core", "hasRole", playerId, "moderator"):await()
```

<ResponseField name="hasRole" type="boolean" required>`true` uniquement si la clé est attribuée.</ResponseField>

## `giveRole`

Attribue un rôle que le personnage ne possède pas encore.

```lua
local ok = Open77.exports.call("bt_core", "giveRole", playerId, "moderator"):await()
```

<ResponseField name="success" type="boolean" required>
  `false` si le personnage est indisponible, si le rôle est invalide ou déjà attribué.
</ResponseField>

## `removeRole`

Retire un rôle attribué.

```lua
local ok = Open77.exports.call("bt_core", "removeRole", playerId, "moderator"):await()
```

<ResponseField name="success" type="boolean" required>
  `false` si le personnage est indisponible ou si le rôle n'est pas attribué.
</ResponseField>
