Appeler ces **exports serveur** avec `Open77.exports.call(...):await()`.

## `getLanguage`

Retourne le code de langue enregistré.

```lua
local language = Open77.exports.call("bt_core", "getLanguage", playerId):await()
```

<ResponseField name="language" type="string" required>
  Valeur enregistrée, ou `fr` si le personnage est indisponible.
</ResponseField>
## `setLanguage`

Enregistre une chaîne de langue libre. Les nouveaux personnages utilisent `fr`,
mais cet export n'applique aucune valeur par défaut.

```lua
local ok = Open77.exports.call("bt_core", "setLanguage", playerId, "fr"):await()
```

<ResponseField name="success" type="boolean" required>`false` sauf si le personnage est chargé et `lang` est une chaîne.</ResponseField>

## `getLastCoords`

Retourne la dernière position persistante.

```lua
local coords = Open77.exports.call("bt_core", "getLastCoords", playerId):await()
```

<ResponseField name="coords" type="Coordinates | nil">
  Position enregistrée, ou `nil` si elle est indisponible.
</ResponseField>

<Expandable title="Afficher les champs de Coordinates">
  <ResponseField name="x" type="number" required>Coordonnée X dans le monde.</ResponseField>
  <ResponseField name="y" type="number" required>Coordonnée Y dans le monde.</ResponseField>
  <ResponseField name="z" type="number" required>Coordonnée Z dans le monde.</ResponseField>
  <ResponseField name="heading" type="number | nil">Orientation facultative en degrés.</ResponseField>
</Expandable>

## `setLastCoords`

Enregistre les champs `x`, `y`, `z` et `heading` facultatif fournis.

<ParamField body="playerId" type="integer" required>Identifiant runtime du joueur.</ParamField>
<ParamField body="coords" type="Coordinates" required>Position copiée telle quelle ; aucune coordonnée par défaut.</ParamField>

```lua
local ok = Open77.exports.call("bt_core", "setLastCoords", playerId, {
    x = -1378.0,
    y = 1270.0,
    z = 123.0,
    heading = 90.0,
}):await()
```

<ResponseField name="success" type="boolean" required>`false` si le personnage est indisponible ou si `coords` n'est pas une table.</ResponseField>

## `getPlaytimeSeconds`

Retourne le temps de jeu cumulé en direct.

```lua
local seconds = Open77.exports.call("bt_core", "getPlaytimeSeconds", playerId):await()
```

<ResponseField name="seconds" type="integer" required>Secondes cumulées en direct, ou `0` si indisponible.</ResponseField>

## `snapshot`

Construit une vue sérialisable fraîche du personnage chargé. Les métiers,
garages, véhicules, constantes vitales et l'état du HUD sont volontairement absents.

<ParamField body="playerId" type="integer" required>Identifiant runtime ; le personnage doit être chargé.</ParamField>

```lua
local player = Open77.exports.call("bt_core", "snapshot", playerId):await()
if not player then return end

print(("%s a joué pendant %d secondes"):format(
    player.characterId,
    player.playtimeSeconds
))
```

<ResponseField name="snapshot" type="CharacterSnapshot | nil">
  État serveur frais, ou `nil` si le personnage n'est pas chargé.
</ResponseField>

<Expandable title="Afficher les champs de CharacterSnapshot">

  <ResponseField name="characterId" type="string" required>Identifiant de personnage BT CORE persistant.</ResponseField>
  <ResponseField name="characterKey" type="string" required>Clé persistante de l'emplacement de personnage.</ResponseField>
  <ResponseField name="firstname" type="string" required>Prénom, potentiellement vide pendant l'onboarding.</ResponseField>
  <ResponseField name="lastname" type="string" required>Nom, potentiellement vide pendant l'onboarding.</ResponseField>
  <ResponseField name="dateOfBirth" type="string | nil">Date ISO `YYYY-MM-DD`.</ResponseField>
  <ResponseField name="sex" type="string" required>Valeur stockée ; l'onboarding utilise `male` ou `female`.</ResponseField>
  <ResponseField name="lifepath" type="string" required>`corpo`, `streetkid`, `nomad`, ou vide avant validation.</ResponseField>
  <ResponseField name="phoneNumber" type="string | nil">Numéro de téléphone persistant généré.</ResponseField>
  <ResponseField name="eddies" type="integer" required>Solde d'espèces courant.</ResponseField>
  <ResponseField name="bank" type="integer" required>Solde bancaire courant.</ResponseField>
  <ResponseField name="others" type="object&lt;string, integer&gt;" required>Soldes extensibles indexés par nom de compte.</ResponseField>
  <ResponseField name="items" type="object&lt;string, integer&gt;" required>Quantités persistantes indexées par nom d'objet.</ResponseField>
  <ResponseField name="xp" type="integer" required>Total d'expérience non négatif.</ResponseField>
  <ResponseField name="permissionLevel" type="integer" required>Niveau numérique de permission.</ResponseField>
  <ResponseField name="roles" type="string[]" required>Clés libres des rôles staff attribués.</ResponseField>
  <ResponseField name="language" type="string" required>Code de langue stocké ; `fr` par défaut.</ResponseField>
  <ResponseField name="lastCoords" type="object | nil">Dernière position avec `x`, `y`, `z` et `heading` facultatif.</ResponseField>
  <ResponseField name="playtimeSeconds" type="integer" required>Temps de jeu cumulé en direct à la création.</ResponseField>
  <ResponseField name="status" type="string" required>Statut persistant ; `active` par défaut.</ResponseField>
</Expandable>
