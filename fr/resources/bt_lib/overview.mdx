<Warning>La version `0.1.0` est en prépublication.</Warning>

`bt_lib` retire les primitives dupliquées tout en laissant la logique métier
à sa ressource propriétaire. Les modules client s'exécutent dans la VM de
l'appelant et utilisent donc ses permissions.

Dépendances : `bt_core >=0.8.1` et
`open77_notifications >=1.0.0`.

```lua
dependency "bt_lib >=0.1.0"
local BT = assert(require("@bt_lib"))
```

Les WebUI plein écran n'envoient aucune largeur/hauteur par défaut : la surface
utilise le viewport réel du joueur. Les dimensions explicites sont réservées
aux textures techniques.
