---
title: "Exports serveur bt_lib"
description: "Notifications, disponibilité personnage, zones et formatage."
icon: "server"
---

| Export | Retour |
| --- | --- |
| `notify(playerId, kind, title, message, durationMs?)` | Identifiant de notification ou `nil, reason`. |
| `requireCharacterReady(playerId, options?)` | Personnage attaché dans `bt_core` ou non. |
| `zoneLookup(entries, x, y, z)` | Attributs de la première zone normalisée correspondante. |
| `formatEddies(amount)` | Entier formaté en `$eb`. |

Ne pas relayer arbitrairement les exports d'une ressource : un appel direct
préserve `GetInvokingResource()`, les autorisations et l'attribution d'audit.
